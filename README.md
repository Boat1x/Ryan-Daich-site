# Ryan Daich - Personal Website

A professional portfolio website for Ryan Daich, showcasing skills, experience, and achievements in cybersecurity.

## Features

- Responsive design for all devices
- Modern UI with smooth animations
- Detailed sections for:
  - About
  - Work Experience
  - Skills
  - Education
  - Certifications
  - Organizations & Leadership
  - Contact information

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)
- Font Awesome icons

## Setup

Simply clone the repository and open index.html in a web browser.

```
git clone https://github.com/yourusername/RyanDaichSite.git
cd RyanDaichSite
```
